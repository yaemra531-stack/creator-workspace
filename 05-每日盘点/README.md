# 📅 每日盘点专区 (Daily Wrap & Sync)

本目录专门用于沉淀每天的终盘盘点、推进成果与未完成卡点。

### 📌 记录标准与规则
- **触发条件**：当一天工作推进事项达到或超过 3 项时，收工前必须建立一篇当天的盘点文件。
- **命名规范**：`YYYY-MM-DD-每日终盘与卡点同步.md`
- **三大必备板块**：
  1. ✅ **今日已完成（Done）**：做了什么，交付了什么。
  2. 🚧 **待攻坚卡点（Blockers & Pending）**：遇到什么技术卡点或未解决问题，如实记录。
  3. 🤖 **下阶段 Agent 一键启动提示词 (Agent Prompt)**：提炼出下一步的明确任务提示词，方便随时无缝续航。
