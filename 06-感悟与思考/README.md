# 感悟与思考

有感悟时和 AI 聊出来的结论。不一定每天一篇，有就记，没有不凑。

## 规则

- 命名：直接用核心结论做文件名，一看就知道讲什么
- 项目第 N 天：以 2026-08-22 为第 1 天
- 升级：某条结论成为稳定原则后，提炼一份放进 `00-架构与初衷/`，原文状态改为"已升级为原则"

## 核心结构：一个认知 + 一个做法

不写长篇大论，每篇只保留两部分：

1. **认知**：一两句话讲透底层逻辑或想法转变（为什么这么想）。
2. **做法**：对应的一个具体动作（接下来干什么，复杂的附链接）。

```markdown
# 核心结论（标题即重点）

## 认知
一句话底层逻辑。

## 做法
对应的一个核心动作（或见具体执行手册链接）。
```
